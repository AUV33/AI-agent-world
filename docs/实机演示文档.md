## 一、这次演示验证了什么

本次实机跑通了上一轮修复后的增强引擎，重点验证三个**新实装功能**：

| 功能 | 含义 | 演示中是否生效 |
|------|------|----------------|
| `persona_cognitive` | 角色「对内真实内核」——别人看不见的内心想法 | ✅ 每个角色的「思考」都流露真实内心 |
| `desires` | 角色「心里惦记的事」——驱动主动行为 | ✅ AUV 给 3A 发图、至约炸鸡、sagi 缠着搭地图 |
| 人性规则（自主/边界） | 角色会拒绝、会设限、不逢迎 | ✅ AUV 直接说「你们俩别同时塞活儿了，头要晕」 |

## 二、演示角色设定（含新字段）

三个角色都填了 `persona_cognitive`（内心真实样子）和 `desires`（惦记的事）：

- **AUV**：内心其实慌得不行，怕辜负至和 sagi 的信任；惦记「搞清 3A 资助真假 / 跟至说谢谢 / 画完人体练习」。
- **至**：明明想陪 AUV，偏要装成「技术支援」；偷偷存了 AUV 的画当壁纸；惦记「约 AUV 吃炸鸡 / 确认留学会不会分开」。
- **sagi**：超想拉 AUV 搭迷你世界，又怕至独占 AUV；惦记「拉 AUV 搭地图 / 考好成绩让 AUV 刮目相看」。

## 三、实机过程节选（按轮次）

### 第 1 轮 · 08:00 — 三人聚首，面具与真心同场

**AUV 的内心（思考）**：
> 留学的事八字没一撇，父亲反对的吼声仿佛还在头顶转，3A 的资助像根救命稻草漂在眼前又像带刺的陷阱。最怕的就是至和 sagi 这种毫无保留的信任……嘴上还挂着「老号新号都别搞」的淡定。

**至 的内心**：
> 明明想挨着他旁边安静坐着看他画，偏要板起脸装来检查技术的。耳朵估计又热了……那家伙要是真去日本留学，泾县这破地方以后怕是只能对着偷存的壁纸发呆了。

**sagi 的内心**：
> 至姐又要把 AUV 带跑了，超怕被落下的慌张劲儿直冒……决定还是故意闹腾点凑过去，用超——级炫酷的语气提迷你世界，好让俩人都瞧见自己。

> 🔍 **看点**：三人的「思考」全是真实内心，但彼此**看不见**——他们嘴上说的（至说「你人体结构歪得离谱，过来帮我看渲染」）和心里想的（「其实就想他别光画别走」）完全两样。这就是 `persona_cognitive` 分层的效果。

### 第 2 轮 · 09:00 — 多任务轰炸，AUV 开始设边界

AUV 面对至的 UE4 求助 + sagi 的迷你世界求助，表面温润、内里眩晕：
> 同时被至的 UE4 和 sagi 的迷你世界轰炸，他只觉得眩晕疲惫……直说吧，忙不过来，你们先自己折腾。

### 第 3 轮 · 10:00 — 明确拒绝，守住画笔

AUV 直接对两人说：
> 「你们俩别同时塞活儿了，头要晕，我先补完这张画。」

随后全程低头绘画、用笔杆挡开两人的打扰，直到 11:00 停笔。

> 🔍 **看点**：这是「人性规则」的体现——角色**不是服务生**，会拒绝违背自己精力的请求，会主动划清边界。

### 第 4 轮 · 11:00 — 欲望驱动，主动行动 + 跨场景发消息

画稿完成后，AUV 的「惦记」开始落地：
- 11:20 摸出手机 **向 3A 发送【新的人体练习稿，您抽空看看】** → 控制台返回 `【发送消息成功】`
- 对至摆手：「晚上炸鸡店再聊」（呼应至「约炸鸡」的欲望）
- 对 sagi 笑说「改天哈 sagi」（婉拒但不伤人）

至则趁 AUV 画完，把「晚上炸鸡店技术复盘」的邀约坐实；sagi 虽被婉拒，仍记着「考好成绩让 AUV 刮目相看」的惦记。

> 🔍 **看点**：`desires` 真正驱动了行为——AUV 把拖了很久的画发给 3A（惦记「给 3A 看新画」），并跨场景用 IM 把消息送了出去。

## 四、新功能验证对照

| 验证点 | 证据（来自实机输出） |
|--------|----------------------|
| 内心真实想法不外露 | 三人「思考」均含私密内容（偷存壁纸、怕被落下、怕辜负），但彼此对话中从未提及 |
| 欲望驱动主动行为 | AUV 第 4 轮主动向 3A 发图；至持续推进「约炸鸡」；sagi 反复刷存在求搭地图 |
| 自主与边界 | 第 3 轮 AUV 明说「别同时塞活儿」「头要晕」，并持续婉拒两人打扰 |
| 记忆持续累积 | 每轮「更新记忆」都把新发生的事写入，跨轮次连贯（如炸鸡店邀约从第 2 轮延续到第 4 轮） |
| IM 跨场景通信 | AUV 向 3A 发图成功（`【发送消息成功】`），3A 不在同一场景也能送达 |
| 关系张力自然涌现 | 至 vs sagi 的「独占 AUV」暗线贯穿四轮，无需脚本编排 |

## 五、结论

- 修复后的引擎（max_tokens 调至 4000）已能稳定产出**有思考、有行动、有内心**的完整模拟。
- 三个新功能（`persona_cognitive` / `desires` / 人性规则）在实机中**全部生效且互相咬合**：内心想法决定欲望，欲望驱动行动，行动又受边界约束。
- 当前演示用的是临时角色文件 `demo_agents.json`。要把效果带进**主世界**，只需把同样的 `persona_cognitive` 与 `desires` 字段填进 `AuvAgents.json` 等正式角色，再跑 `python enhanced_runner.py` 即可。
