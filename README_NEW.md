# 致敬传奇AI项目

> 一个多角色 AI 模拟 + 故事生成项目：让一批有血有肉的"人"在同一个世界里各自生活、互动，再把他们的生活记录转成小说。
> 当前主线：**明远中学 302 寝室**（六名高中室友 + 班主任 + 物理张老师 + 篮球队教练）。
> 核心能力：任何角色设定都能跑、任何日志都能转故事、剧情出现新角色自动生成人设。

---

## 一、项目是干什么的

1. **模拟**：读取角色设定（JSON），每个角色由 AI 驱动，在校园场景里独立思考、行动、移动、互相发消息。
2. **记录**：把每个角色每轮"干了什么"按原始格式落盘成日志（单步记录：思考/记忆/动作/场景状态）。
3. **自动造人**：剧情中出现新角色时，自动生成详细人设并加入模拟，后续按人设行动。
4. **转换**：把日志自动整理成小说（群像叙事 / 轻小说 / 小说式排版，含人物关系网、心理描写）。

## 五、核心功能详解

### 1. 多角色模拟（校园篇 `run_school.py`）

**单步记录模式**：每轮所有角色**依次单独行动**，日志按
`角色名 场景 ：` + 思考/更新记忆/动作 + 场景状态 逐条记录 —— 只记录"每个人干了什么"。

```powershell
& $PY "D:\致敬传奇AI项目\记录\程序\run_school.py" [轮数] [--quiet]
```
- 不传轮数 = 无限跑，Ctrl+C 停止；`--quiet` = 只写日志文件
- 日志默认存到 `记录\原始日志\`，格式 `明远中学_原始记录_时间戳.txt`
- **自动造人**：每轮结束后自动扫描本轮剧情，若出现剧情中不存在的新角色（被角色主动发消息/申请好友的对象），会**实时生成详细人设 → 加入模拟 → 持久化到 schoolAgents.json**，该角色后续轮次按人设正常行动。

### 2. 故事转换器 `story_converter.py`

自动检测日志格式并选择生成方式，**任何日志都能转**：

| 日志类型 | 自动生成的模式 |
|---|---|
| 校园群体段日志（`第N段|`） | 六人群像小说《302寝室的日常》 |
| 校园单步记录（`名字 场景 ：`） | 六人群像小说（按轮/场景整合 + 心理描写） |
| 日本篇单步记录 | 轻小说精简模式《平行群像物语》 |
| 其他单步（Jec/malaya/Auv） | 小说式排版 |

### 3. 角色人设生成器 `character_generator.py`

```powershell
& $PY "D:\致敬传奇AI项目\记录\程序\character_generator.py" generate "张伟" --info "17岁，懒散，爱打游戏" --enhance "多写具体事例" --out schoolAgents.json
```
- 本地优先，AI 扩写兜底
- 学生模板自动包含：普通高中生、不完美、有劣根性、学校禁带手机（有也是偷偷藏）
- 成人（老师/教练等）自动切换成人人设模板

### 4. API 与网络适配

- **小米 API**：`caller.py` 调用 `https://api.xiaomimimo.com/v1/chat/completions`，模型 `mimo-v2.5-pro`，Key 在 `caller.py` 顶部（`API_KEY`）。
- **DNS 补丁**：本机路由器 DNS 间歇性故障（域名解析超时），`caller.py` 导入时自动 `dns_override.patch()`，改为走公共 DNS（阿里 223.5.5.5 / 腾讯 119.29.29.29 等）UDP 查询，无需管理员权限。
- **提速**：`caller.call_model` 支持 `max_tokens`；`engine.py` 已给思考/动作（800）与场景更新（400）设上限，避免模型超写拖慢。

### 1. 增强版记忆系统 (`enhanced_memory.py`)

- 情绪影响行为决策
- 情绪历史记录

- 高中生作息时间表
- 活动状态机（上课/吃饭/睡觉/自由活动）
- 跨天记忆
- 随机事件

### 4. 思考日志系统 (`thinking_logger.py`)

- 记录AI的内心思考过程
- 分离思考与回复
- 支持思考分析
- JSONL格式便于后续处理

## 十、已知问题与注意事项（重要）

1. **DNS**：本机 DNS 可能超时导致"域名解析失败"，`caller.py` 已自动处理；若手工调试请先 `import dns_override; dns_override.patch()`。
2. **影子进程**：本环境会给后台 Python 派生一个 codex-runtime 影子子进程（命令行相同）。`run_school.py` 已有**进程锁**（`记录\程序\.run_school.lock`，运行时会自动创建/清理），影子进程会自动退出，**不要手动去杀影子进程**（可能牵连主进程）。
3. **长任务**：前台长命令可能被工具中断；跑多轮建议用后台方式（如 `Start-Process`）并轮询日志，或分多次跑。
4. **控制台中文乱码**：PowerShell 控制台（GBK）显示 UTF-8 输出可能乱码，**文件内容是正确的**；如需看内容直接 `Get-Content -Encoding UTF8`。
5. **API 偶发空返回**：小米 API 偶发返回空 content，运行脚本有 4 次重试；仍失败会报错退出，重跑即可。
6. **无断点**：`run_school.py` 单步模式无断点续跑，进程中断后需重跑（旧日本篇断点脚本已移入 `记录\归档\`）。

## 十一、风格约定（写人设/故事时请遵守）

- **人无完人**：所有人设都要**真实、不完美**，劣根性必须有——这不是"缺点"，而是根植于人性深处的弱点。圣人不存在，每个人都戴着面具生活。
- **劣根性的普遍性**：虚荣、嫉妒、逃避、撒谎、攀比、记仇、自私、功利……这些不是某个群体的专利，而是人类的共性。年龄、身份、职业只是表象，内核都一样。
- **高中生设定补充**：高中**禁带手机**——没手机，或偷偷藏一部从不在人前用。
- **成年人设定补充**：老师也会偏心、也会有私心；父母也会自私、也会控制；领导也会虚伪、也会推卸。不要把任何群体"圣人化"。
- 故事语言风格参考轻小说（语言格式可参考番茄小说《三流人类生存指南》），克制、生活化、带淡淡青春气；不写"三流人类生存指南"字样。
- 原始记录 = 每个人单独干了什么；小说 = 群体叙事整合。
